## Functional boundaries

The implemented scope includes the Phase 1 workspace, Phase 2 Company/catalog foundation, Phase 3 Procurement, Stock Transfer/Adjustment, Sales Delivery and Invoice settlement, plus Phase 4 operational Reports, Employees, Leave Requests and manual double-entry Journals/ledgers, single-level BOMs, full Work Order production and released-material planning. Company deletion is soft deactivation, preserving history. Demo Dashboard drafts remain browser-local; operational processing requires live mode. The legacy `/documents` endpoint and demo Reports still return read-only snapshots; live Reports use actual posted Invoices. Operational Payment is an Invoice settlement record; manual financial Journals/ledgers are implemented separately without automatic integration. CRM activities, advanced Accounting, HR Attendance/payroll/entitlements, and advanced Manufacturing execution remain unimplemented.
